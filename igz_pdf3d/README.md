# igz_pdf3d — 3D PDF export for IngeTrazo

Select what you want to share (or nothing, for the whole visible model), click
the **3D PDF** toolbar button (or Extensions ▸ Export 3D PDF…), set a title
and a note, and save. The PDF opens in Adobe Acrobat Reader and Bluebeam Revu
as an interactive 3D model with a model tree by layer and object, materials
and textures, and named views. Other viewers show a snapshot of the viewport.

Model units are inches by default (Metric switch: metres). Set your viewer's
measure tool to the same unit.

GPL-3.0-or-later. Requires IngeTrazo 0.5.8 or later. No dependencies.
